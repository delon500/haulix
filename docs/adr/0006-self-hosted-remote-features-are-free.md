# 0006. Remote features are free when self-hosted

**Status:** Accepted, 2026-10-18

## Context

The web dashboard, sync and the full mobile app are Pro features because our relay servers cost money, but self-hosters run their own.

## Decision

Remote features are free when the user runs the relay themselves, and Pro only when they use ours.

## Consequences

Pro pays for real running costs, and self-hosters, an influential group, aren't charged for infrastructure they provide.
