# Feature Catalogue — v0.5 Beta

v0.5 adds 31 features (F-028–F-058) that turn a reliable downloader into one people rely on daily: automation, library tidying, Linux support and a more forgiving interface. It ends as a public beta. The format, personas and tags are the same as the v0.1 file.

## Core download engine

These six features make downloads safer, more controllable, and fully owned by our own engine.

### F-028 Integrity checks (checksums, partial-file repair)

**Core download engine · v0.5 · Free**

**What it is:** After a download finishes, the app checks the file is complete and undamaged. If a website publishes a checksum (a fingerprint of the file), the app compares against it. If part of a file is damaged, only that part is downloaded again.

**User story:** As Sam, I want downloaded files verified automatically, so that I never install software or use data from a corrupted file.

**Scenario:** Sam downloads a 4 GB Linux ISO. The site lists its SHA-256 checksum, which the app picks up from the page. The check fails on one 20 MB segment, so the app re-downloads just that segment, and the second check passes.

**Acceptance criteria:**

- Supports MD5, SHA-1, SHA-256 and SHA-512 checksums, entered by the user or detected from the download page or a .sha256 file next to it.
- A failed check marks the download clearly and never silently keeps a bad file.
- Damaged segments are re-downloaded individually when the server supports partial downloads.
- Checking a 4 GB file takes under 30 seconds on a typical laptop SSD.

### F-029 Download into archives, or auto-extract (zip, rar, 7z)

**Core download engine · v0.5 · Free**

**What it is:** When a download is a compressed archive, the app can unpack it automatically when it finishes, into a folder named after the archive, and optionally delete the archive afterwards.

**User story:** As Diego, I want downloaded asset packs unpacked automatically, so that they're ready to drop into my editing project.

**Scenario:** Diego downloads a 3 GB zip of sound effects. When it finishes, the app unpacks it into "Sound Effects Pack/" and moves the zip to the bin, ready to use.

**Acceptance criteria:**

- Zip, 7z, rar, tar and gz archives can be extracted automatically when the download completes.
- Auto-extract can be turned on globally, per queue, or per download.
- Multi-part archives (for example part1.rar, part2.rar) are extracted once all parts are downloaded.
- Password-protected archives prompt for the password instead of failing silently.
- Extraction never writes outside its target folder, even if the archive is crafted to try.

### F-030 Proxy, SOCKS and VPN support (including per download)

**Core download engine · v0.5 · Free**

**What it is:** Downloads can be routed through a proxy server (HTTP or SOCKS5), either for everything or only for particular sites or downloads. This is common in workplaces, for privacy, and for reaching content limited by region.

**User story:** As Priya, I want the app to use my company's proxy, so that downloads work on the office network the same way my browser does.

**Scenario:** Priya's office network blocks direct downloads. She enables "Use system proxy settings" once, and every download goes through the company proxy automatically.

**Acceptance criteria:**

- Supports HTTP, HTTPS and SOCKS5 proxies, with optional username and password.
- Can follow the operating system's proxy settings automatically.
- A different proxy, or none, can be set per site or per download.
- Proxy settings apply to yt-dlp media downloads as well as normal downloads.
- A "Test connection" button confirms the proxy works before saving.

### F-031 Rate limiting per download, per site or globally

**Core download engine · v0.5 · Free**

**What it is:** Users can cap download speed for everything, for a particular site, or for one download, so downloading doesn't use the whole connection.

**User story:** As Priya, I want to cap the app's total speed during work hours, so that my video calls and colleagues on the same network aren't affected.

**Scenario:** Priya sets a global limit of 5 MB/s on her 20 MB/s connection. Downloads continue in the background while her video calls stay smooth.

**Acceptance criteria:**

- Speed limits can be set globally, per queue, per site and per download.
- Limits can be changed while downloads run, and take effect within 2 seconds.
- Actual speed stays within 10% of the limit, averaged over 10 seconds.
- A quick "Turbo / Limited" toggle is available from the main window and the system tray.

### F-032 Duplicate detection before downloading

**Core download engine · v0.5 · Free**

**What it is:** Before starting a download, the app checks whether the same file is already downloaded or queued, and asks what to do instead of creating a second copy.

**User story:** As Maya, I want to be warned when I'm about to download something I already have, so that I don't waste data and storage on duplicates.

**Scenario:** Maya clicks a lecture video she downloaded last week. The app shows "You already have this file in Downloads/Lectures" with options to open it, download again, or cancel.

**Acceptance criteria:**

- Duplicates are detected by matching link, and by filename plus size, for items in history or the queue.
- For media, matching uses the site's video ID, so different links to the same video are recognised.
- Users choose: open the existing file, download again with a new name, replace it, or cancel.
- A "remember my choice" option sets the default for future duplicates.

### F-033 Own Rust segmented downloader (replaces aria2)

**Core download engine · v0.5 · Free**

**What it is:** v0.1 relies on aria2, an existing download program, to do the segmented downloading. v0.5 replaces it with our own downloader built into the engine. Users notice no difference at first, but it makes later features possible: polite bandwidth use, mirror failover and metered-connection awareness.

**User story:** As Sam, I want the app to control every part of a download itself, so that advanced features like smart throttling and mirror switching work reliably.

**Scenario:** Behind the scenes, Sam's downloads now run on the built-in engine. Speeds are the same as before, but the app now reports which mirror each segment came from and adapts its connection count per server.

**Acceptance criteria:**

- Matches or beats aria2's speed on a standard set of test files and servers.
- Supports everything v0.1 did with aria2: segments, resume, cookies, headers, proxies and rate limits.
- Passes the same crash and resume tests as v0.1 (100 forced kills, zero corrupted files).
- Can be switched back to aria2 in settings during the beta, as a fallback.
- Uses no more memory than aria2 for the same downloads.

These five features make saved media more complete and bring the extension to more browsers.

**Acceptance criteria:**

- The thumbnail is embedded as cover art in MP4, MKV, MP3 and M4A files.

- Each item can be turned on or off in settings.

- Removed segments are listed in the download details.

### F-038 Batch link grabber with filters

**Browser integration · v0.5 · Free**

**User story:** As Sam, I want to paste a long list of links and filter it down, so that I only queue the files I need without sorting them by hand.

**Scenario:** Sam pastes 200 links copied from a forum post. He filters to ".mkv only, over 500 MB", which leaves 18 files, and queues them in one click.

**Acceptance criteria:**

- Accepts pasted text containing many links, a text file of links, or links collected from a web page.
- Filters by file type, size range, words in the name, and site; filters can be combined.
- Wildcards and simple patterns (for example, "episode\*") are supported for names.
- Shows the count of selected files and their total size before queueing.
- Handles 5,000 links without slowing down.

## Queue, scheduling and network

These four features let downloads run at the right time and adapt to the connection without the user stepping in.

### F-039 Time-window scheduling

**Queue and scheduling · v0.5 · Free**

**What it is:** Each queue can be set to run only during chosen hours and days, for example overnight, or outside working hours. Downloads wait until their window opens, then start automatically.

**User story:** As Diego, I want big downloads to run only overnight, so that my connection is free for uploads and calls during the day.

**Scenario:** Diego sets his "Overnight" queue to run from 23:00 to 07:00. He adds 80 GB of footage at lunchtime. Nothing starts until 23:00, and the queue pauses itself at 07:00 if anything is left.

**Acceptance criteria:**

- Each queue can have one or more time windows, set by hours and days of the week.
- Downloads start within 1 minute of their window opening and pause when it closes, keeping their progress.
- Windows use the computer's local time and handle daylight-saving changes correctly.
- A "Start now anyway" option overrides the schedule for one download or queue.
- The queue shows when it will next run.

### F-040 Start, stop or shut down after the queue finishes

**Queue and scheduling · v0.5 · Free**

**What it is:** Users choose what happens when a queue finishes: do nothing, close the app, put the computer to sleep, or shut it down. One queue can also start another when it finishes.

**User story:** As Diego, I want my computer to shut down once overnight downloads finish, so that it isn't left running for hours for no reason.

**Scenario:** Diego sets "Shut down when finished" on his overnight queue. The last file completes at 03:40; the app shows a 60-second countdown, nobody cancels it, and the computer shuts down.

**Acceptance criteria:**

- Options when a queue finishes: nothing, quit app, sleep, hibernate (where supported), shut down, or start another queue.
- Sleep and shut-down show a 60-second countdown with a Cancel button first.
- Failed downloads don't block the action; they're listed in a summary on next launch.
- The action only runs once the whole queue is finished, not after each download.

### F-041 Adaptive connection count per server

**Network intelligence · v0.5 · Free**

**What it is:** Instead of always using the same number of connections, the app learns what each server handles best. It adds connections while speed improves, and backs off when a server slows down or starts refusing them.

**User story:** As Sam, I want the app to find the best number of connections for each server automatically, so that I get maximum speed without being blocked.

**Scenario:** Sam downloads from a server that limits each user to 4 connections. Instead of failing with errors at 16, the app notices the refusals, settles on 4, and remembers that for the next download from that server.

**Acceptance criteria:**

- The app adjusts connections per download based on measured speed and server responses.
- Errors that mean "too many connections" (such as HTTP 429 or 503) cause it to back off, not fail.
- The best setting per server is remembered for future downloads.
- Users can still set a fixed number manually for any site.

### F-042 Network-change handling (Wi-Fi, mobile, VPN)

**Network intelligence · v0.5 · Free**

**What it is:** When the connection changes, for example moving from Wi-Fi to a phone hotspot, switching networks, or turning a VPN on or off, downloads pause and resume smoothly instead of failing or stalling.

**User story:** As Priya, I want downloads to carry on when I switch networks, so that moving from the café Wi-Fi to my phone hotspot doesn't break anything.

**Scenario:** Priya's café Wi-Fi drops and her laptop switches to her phone's hotspot. Her downloads pause for a few seconds, reconnect on the new network, and continue from where they were.

**Acceptance criteria:**

- A network change is detected within 5 seconds on Windows and macOS.
- Active downloads pause and resume on the new connection automatically, keeping their progress.
- Stalled connections (no data for 30 seconds) are reconnected automatically.
- When there's no connection at all, downloads wait and retry with increasing delays, without filling the screen with errors.

## Automation

These four features let the app do repetitive work for users. Three of them are the first Pro features; free users get a limited version of each.

### F-043 Rules engine (match, then format, folder and rename) ★

**Automation · v0.5 · Pro · ★ Differentiator**

**What it is:** Users create "if this, then that" rules for downloads. A rule matches on things like the site, file type, size or words in the name, then applies actions: which quality or format, which folder, how to name the file, which queue. Think of it as email filters, but for downloads.

**User story:** As Maya, I want every lecture from my university's video site saved as 720p into my course folder automatically, so that I never have to choose settings or move files by hand.

**Scenario:** Maya creates a rule: "If the site is lectures.myuni.edu, download at 720p with English subtitles, save to /Uni/2026/{course}/, and name it {date} – {title}." From then on, every lecture she clicks lands in the right folder with the right name.

**Acceptance criteria:**

- Conditions: site, link pattern, file type, size, words in the title or filename, and source playlist or channel; conditions can be combined with AND / OR.
- Actions: quality and format, folder, filename template, queue, priority, subtitles, and post-download actions.
- Rules run in a set order; the first matching rule applies unless set to continue to the next.
- A "Test rule" button shows which recent downloads it would have matched.
- Free users get a limited version; the exact limits are set with pricing before v1.0.

### F-044 Subscriptions: channels, playlists, podcasts, RSS

**Automation · v0.5 · Pro**

**What it is:** Users subscribe to a channel, playlist, podcast or RSS feed. The app checks for new items regularly and downloads them automatically, using the user's chosen settings or rules.

**User story:** As Priya, I want new episodes of my favourite podcasts and channels downloaded automatically, so that they're ready offline before every trip.

**Scenario:** Priya subscribes to three podcasts and a tech channel, set to audio-only. Every new episode downloads overnight, and the night before her flight her phone sync folder has everything from the past week.

**Acceptance criteria:**

- Supports channels and playlists on supported video sites, podcast RSS feeds, and general RSS/Atom feeds with downloadable links.
- Check frequency can be set per subscription (from hourly to weekly).
- Options: download only new items from now on, or a chosen number of recent items too; keep only the latest N items.
- Items already downloaded are never downloaded again.
- Free users get a limited version; the exact limits are set with pricing before v1.0.

### F-045 Clipboard monitoring

**Automation · v0.5 · Free**

**What it is:** When turned on, the app watches for download links copied to the clipboard and offers to download them with one click, without opening the app or pasting.

**User story:** As Diego, I want the app to notice when I copy a video link, so that I can queue it in one click while browsing on any app.

**Scenario:** Diego copies a video link from a chat message. A small prompt appears in the corner: "Download this video?" He clicks Download, and it's queued with his default settings.

**Acceptance criteria:**

- Off by default; turned on in settings or during first-run setup.
- Recognises direct file links and supported media links; ignores other copied text.
- The prompt disappears on its own after 8 seconds if ignored.
- The same link isn't offered twice in a row.
- Clipboard content is never stored or sent anywhere, beyond links the user chooses to download.

### F-046 Post-download actions (convert, move, unzip, script, upload)

**Automation · v0.5 · Pro**

**What it is:** Actions that run automatically when a download finishes: convert to another format, move or copy to a folder, unzip, open the file, or run a custom script. They can be set for a single download, a queue, or through rules.

**User story:** As Diego, I want downloaded footage converted to my editor's preferred format automatically, so that clips are ready to edit the moment they arrive.

**Scenario:** Diego sets his "Footage" queue to convert every finished download to ProRes and move it to his project drive. Each clip arrives in his editing folder, already converted.

**Acceptance criteria:**

- Built-in actions: convert (using ffmpeg presets), move, copy, extract archive, open file, show in folder.
- Custom scripts can run with the file path passed in, with a warning explaining the security risk when enabling them.
- Actions can be chained in order, and a failed action is reported without losing the downloaded file.
- Actions can be attached to a single download, a queue or a rule.
- Free users get a limited version; the exact limits are set with pricing before v1.0.

## Library management

These three features keep the downloads folder tidy without the user doing any filing.

### F-047 Auto-organize by type, site, date or rules

**Library management · v0.5 · Free**

**What it is:** Finished downloads are sorted into folders automatically: by type (Videos, Music, Documents, Software, Archives), by the site they came from, by date, or by the user's rules. The usual messy Downloads folder never builds up.

**User story:** As Maya, I want my downloads sorted into sensible folders automatically, so that I can find files without digging through hundreds of items.

**Scenario:** Maya downloads a PDF, a lecture video, an installer and a zip in one afternoon. Each ends up in its own folder: Documents, Videos, Software and Archives.

**Acceptance criteria:**

- Default folders by type are created on first use, with sensible file-type groups that users can edit.
- Folders can also be organised by site, by date (year/month), or by a combination.
- Rules (feature F-043) override the default sorting when they match.
- Changing the sorting scheme doesn't move files already downloaded, unless the user asks it to.
- Users can turn auto-organize off and keep a single download folder.

### F-048 Smart renaming templates

**Library management · v0.5 · Free**

**What it is:** Files are named from a template using details like title, channel, date, playlist position and resolution, instead of whatever name the website gave them. Characters that break filenames are removed automatically.

**User story:** As Diego, I want downloaded files named consistently, so that I can sort and find footage by source and date in my editing software.

**Scenario:** Diego sets his template to {upload\_date} – {channel} – {title} \[{resolution}\]. A video that would have been saved as "video\_1080p\_final(2).mp4" is saved as "2026-09-14 – City Drone Shots – Harbour at Dawn \[1080p\].mp4".

**Acceptance criteria:**

- Templates support at least: title, channel or author, upload date, download date, site, playlist name and position, resolution, format and original filename.
- A live preview shows an example filename while the template is edited.
- Characters not allowed in filenames on Windows, macOS or Linux are removed or replaced.
- Overly long names are shortened safely to fit system limits.
- Templates can be set globally, per queue, or through rules.

### F-049 Deduplication across the library

**Library management · v0.5 · Free**

**What it is:** The app scans the user's download folders for identical files, even with different names, and helps remove the extra copies to free up space. This differs from feature F-032, which prevents new duplicates before downloading.

**User story:** As Sam, I want to find and remove duplicate files across my download folders, so that I get back storage wasted on copies I didn't know I had.

**Scenario:** Sam runs a duplicate scan on his 900 GB downloads drive. The app finds 140 duplicate files using 62 GB, grouped by set. He keeps the newest copy of each and moves the rest to the bin in one step.

**Acceptance criteria:**

- Duplicates are found by file content (size, then checksum), not by name.
- Results are grouped, showing each copy's location, date and size, plus total space to recover.
- Users choose which copy to keep, with helpers such as "keep newest" or "keep in this folder".
- Removed files go to the system bin, never permanently deleted by the app.
- Scanning 100,000 files completes without freezing the app and can be paused.

## Platforms, security and privacy

These three features bring the app to Linux and add protection against tampered files and unwanted history.

### F-050 Desktop: Linux

**Multi-device and remote · v0.5 · Free**

**What it is:** The app becomes available on Linux, with the same features as Windows and macOS. Linux users are a small share of desktop users but an influential one: developers, self-hosters and privacy-minded people who recommend tools to others.

**User story:** As Sam, I want a native Linux version, so that I can use the same app on my Linux workstation as on my other machines.

**Scenario:** Sam installs the Flatpak on Fedora and the .deb on his Ubuntu laptop. Both work like the Windows version, and the browser extension connects to the app in Firefox on Linux.

**Acceptance criteria:**

- Runs on Ubuntu 22.04+, Debian 12+, Fedora 39+ and Arch, on x64 and ARM64.
- Distributed as AppImage, Flatpak, .deb and .rpm.
- Browser extension connection (native messaging) works in Chrome, Firefox and Brave on Linux.
- Follows the desktop's light/dark theme and notification system on GNOME and KDE.
- All v0.1 and v0.5 features pass the same automated tests as on Windows and macOS.

### F-051 Automatic checksum and signature verification

**Security and privacy · v0.5 · Free**

**What it is:** For software downloads, the app checks that the file really comes from its publisher and hasn't been tampered with, using published checksums and digital signatures (such as GPG signatures or the operating system's code-signing checks). Feature 28 catches damaged files; this feature catches deliberately altered ones.

**User story:** As Sam, I want the app to confirm that software I download is genuinely from its publisher, so that I don't install something that was swapped for malware on a compromised mirror.

**Scenario:** Sam downloads an open-source tool from a mirror site. The app fetches the publisher's signature file from the official site and checks it. The signature doesn't match, so the app blocks the file with a clear warning, and Sam downloads from the official site instead.

**Acceptance criteria:**

- Detects and checks GPG signature files (.sig, .asc) published alongside a download.
- Checks the code signature of Windows installers and macOS apps, showing the verified publisher name.
- A failed check blocks the file with a clear warning; the user can review details and choose to keep it.
- Results (verified, unsigned, failed) are shown on each download.
- Verification never sends the file itself anywhere.

### F-052 Private mode (no history)

**Security and privacy · v0.5 · Free**

**What it is:** Like a browser's private window, downloads made in private mode leave no trace in the app: no history, no thumbnails, no record in the queue after they finish. The files themselves are saved wherever the user chooses.

**User story:** As Priya, I want to download some files without them appearing in the app's history, so that people who use my laptop don't see them.

**Scenario:** Priya switches on private mode to download documents for a confidential project. When she turns it off, the app's history shows nothing from that session.

**Acceptance criteria:**

- Private mode can be toggled from the main window, and applies to downloads started while it's on.
- No history, thumbnails, logs or search index entries are kept for private downloads after they finish.
- An unmistakable indicator shows while private mode is on.
- Private downloads still resume after a crash, but their records are removed as soon as they finish.
- Users can also choose "Clear all history" at any time.

## UX and accessibility

These six features make the app easier for beginners, faster for experts, and usable in more languages.

### F-053 Minimal mode and power-user mode

**UX and UI · v0.5 · Free**

**What it is:** Two levels of interface. Minimal mode shows only the essentials (paste a link, see progress), for people who just want things downloaded. Power-user mode shows everything: per-download settings, connection details, queues and logs.

**User story:** As Maya, I want a simple view without technical settings, so that the app never feels overwhelming. As Sam, I want every detail and control visible, so that I can fine-tune downloads.

**Scenario:** Maya keeps the default minimal mode: a link box and a clean list. Sam switches to power-user mode and sees connection counts, server details, speed graphs and the full queue manager.

**Acceptance criteria:**

- Minimal mode is the default for new users; power-user mode is one switch away in settings and the menu.
- Switching modes changes only what is shown, never the user's settings or downloads.
- Every feature remains reachable in minimal mode, through menus, even if hidden from the main view.
- First-run setup asks which mode the user prefers.

### F-054 Plain-language errors with one-click fixes ★

**UX and UI · v0.5 · Free · ★ Differentiator**

**What it is:** When something goes wrong, the app explains it in everyday words and offers a button that fixes it, instead of showing codes like "HTTP 403" or "ERROR: unable to extract". This is one of the clearest differences from IDM, JDownloader and yt-dlp, which all show raw technical errors.

**User story:** As Maya, I want errors explained in plain language with a fix I can click, so that I can solve problems myself without searching online.

**Scenario:** A download fails because the site needs a login. Instead of "HTTP 403 Forbidden", Maya sees: "This site needs you to be logged in. Sign in to the site in your browser, then click Retry with browser login." She clicks it and the download works.

**Acceptance criteria:**

- The 25 most common failures each have a plain-language message and, where possible, a fix button (for example: retry with browser login, update site support, change proxy, free up disk space).
- Messages avoid jargon; technical details are available behind a "Details" link for advanced users and bug reports.
- Messages are written for a reading age of about 12 and tested with non-technical users.
- Errors with no known fix offer "Copy details" and a link to help.
- At least 80% of failures in beta telemetry (from users who opt in) map to a plain-language message.

- Shortcuts follow each system's conventions (Ctrl on Windows and Linux, Cmd on macOS).

**What it is:** Removing downloads from the list, deleting files, or moving items between queues can be undone straight away with Ctrl+Z or an "Undo" button, so mistakes are never permanent.

**User story:** As Maya, I want to undo an accidental delete, so that one wrong click doesn't cost me a file I needed.

**Scenario:** Maya selects old downloads to clear from the list and accidentally includes this week's lectures. An "Undo" bar appears for 10 seconds; she clicks it, and everything is back.

**Acceptance criteria:**

- Removing items, deleting files, clearing history and moving between queues can all be undone.
- An "Undo" bar appears for 10 seconds after each such action; Ctrl+Z / Cmd+Z works too.
- Files deleted through the app go to the system bin, so they can be recovered even after the undo window.
- The last 20 actions can be undone in order.

### F-058 Community translations

**Accessibility and localization · v0.5 · Free**

**What it is:** The app's text can be translated into other languages by volunteers through an online translation platform. Translations ship with app updates, so users worldwide can use the app in their own language.

**User story:** As a user in Brazil who prefers Portuguese, I want the app in my language, so that I understand every option and message.

**Scenario:** Volunteers translate the app into Portuguese on the project's translation page. The next update includes it, and a Brazilian user's app switches to Portuguese automatically because that's her system language.

**Acceptance criteria:**

- All interface text is stored in translation files, with no text built into the code.
- Translations are managed on a public platform (such as Weblate or Crowdin) that volunteers can join.
- The app follows the system language by default, and users can change it in settings.
- Untranslated text falls back to English, never to blank or broken labels.
- Dates, numbers and file sizes are shown in each language's local format.
- At launch of the beta, at least 5 languages are 90% or more complete.
